# ArtSpace — финальная сборка

Готов к защите/деплою. Собран 2026-11-07.

## Запуск
    python3 make_artspace.py

Всё в папке `site/`. Открывай `site/index.html` в браузере
(лучше через локальный сервер: `python3 -m http.server -d site`).

## Страницы
index, catalog, product, order, tickets, favorites, reviews,
my-reviews, organizers, about, contacts, privacy, 404.

## Сценарии
- Поиск + фильтры + сортировка + метки в каталоге (URL синхронизируется).
- Подборщик из 3 вопросов на главной.
- Избранное, «Мои записи» (билеты с QR, печать, отмена).
- Отзывы: форма, список, «только мои», удаление.
- Запись: тариф, гости, валидация, итог.
- Тёмная/светлая тема, prefers-reduced-motion, печать билета.
- 404, sitemap, robots, manifest, _redirects (Netlify), .htaccess (Apache).

Все данные — localStorage. Сервера нет: письма/оплата не уходят.

## Патч v2
Применён `patch_artspace.py` (повторный запуск безопасен; после пересборки сайта запустите его снова).

- **Тема и уведомление** запоминаются на всех страницах; смена темы — круговая волна из кнопки (View Transitions, с запасным вариантом).
- **Иллюстрации**: `images/art/` — SVG для hero, организаторов и категорий (фото из интернета не нужны).
- **Меню**: Главная, Каталог, Live, Подборки, Организаторы, О проекте.
- **Live** (`live.html`): обратный отсчёт до ближайшего события, «идёт сейчас», «скоро», расписание, «Удиви меня».
- **Подборки** (`collections.html`): 8 готовых подборок, ссылка вида `collections.html#free`.
- **Быстрый поиск**: Ctrl+K или `/`. **Страница события**: «В календарь (.ics)», «Поделиться».
- **Анимации**: полоса прокрутки, подсветка карточек, параллакс в hero, конфетти после записи, плавная кнопка «Наверх».
- **Запуск**: `python3 serve.py` (открывать через http, а не двойным кликом по файлу — тогда всё хранится надёжнее).
